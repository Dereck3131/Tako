# Mascot Assets

Drop your Tako mascot PNG or SVG exports in this folder using these filenames:

- `happy.png` (or `happy.svg`)
- `sad.png` (or `sad.svg`)
- `peeking.png` (or `peeking.svg`)
- `celebrating.png` (or `celebrating.svg`)

Until files are added here, `<TakoMascot />` automatically renders the built-in Tako vector mascot so the site works out of the box.
